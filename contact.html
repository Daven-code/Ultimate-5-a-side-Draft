What to include

To make it easier to help, include any relevant details such as the game mode, device or browser used, the room code if the issue relates to an online game, and a short description of what happened.

Leaderboard requests

For leaderboard correction or removal requests, include the displayed username, approximate submission date, game mode and score if known. Avoid sending passwords or sensitive personal information.
